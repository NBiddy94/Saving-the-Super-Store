# Saving-the-Super-Store
https://public.tableau.com/views/sprint4project_17302454189500/profitcenters?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

A project in Tableau to review the operations and increase profitability for a company to avoid bankruptcy.

Identified the important causes of profit and loss with the company by analyzing products within different dimensions.
Evaluated the benefits of advertising between time and geography by connecting to data sources and preparing data for analysis, using custom queries to import data from SQL databases.
Calculated return items to determine if some products have excessive rates of being returned consistently by creating visualizations to compare between products and customers returns. This would help business executives understand the cause of profit lost within their company.
